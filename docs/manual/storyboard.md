# 操作説明動画（docs/assets/manual.mp4）の絵コンテ

Research OS v0.1.2 の TUI の使い方を、1 場面ずつ静止画で見せる説明動画。
各場面で **説明する UI を赤枠で囲み**、**画面の下に日本語の説明** を出す。

- 生成：`uv run python scripts/make_manual_video.py`（出力 `docs/assets/manual.mp4`）
- 画面は Textual の Pilot で実際に操作して SVG に書き出したもの（120 列 × 36 行）。論文はサンプルデータ
- 1920×1080・30fps・H.264。場面ごとに 4〜7 秒、場面の切り替えは短いフェード
- 赤枠の位置はウィジェットの領域（セル単位）から計算する。手で座標を書かない（画面が変わっても追従する）

## 場面

| 0 | — | — | タイトル：Research OS 操作ガイド v0.1.2 |
| 1 | 画面全体 | 起動 | `research-os tui` で起動。上からヘッダ・タブ・メイン・Agent 欄・ステータスバー |
| 2 | ヘッダ | — | アプリ名・研究テーマ・バージョン・時刻 |
| 3 | フェーズタブ | — | 1〜7 キーで研究フェーズを切り替える |
| 4 | Neko | — | Agent の状態を顔で表す |
| 5 | Inbox の集計行 | — | 今週の取り込み数・未処理・読む枠・RQ ごとの中核論文 |
| 6 | Inbox 一覧 | — | スコア順。2 行目にスコアの理由 |
| 7 | Preview | — | 書誌・スコアの内訳表・LLM の判定理由・要旨 |
